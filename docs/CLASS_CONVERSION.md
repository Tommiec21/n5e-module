## Use

1. Install the private alpha15 release on supported Foundry13/dnd5e5.3.3 and enable the module.
2. Configure Settings > N5e class library > Import three classes. Import the whole library before adding a class, so every native grant/choice resolves.
3. Find N5e Classes / class name / Class and drag it onto a fresh character; use the native advancement flow for HP, starting proficiencies and feature choices. Subclasses are under the same class folder.
4. Set later levels through native class advancement. Previously prepared test actors can retain an explicit N5e level override; keep that testing value aligned with class level, or use a fresh character without an override.
5. Refined Focus has a native uses counter, Spend Focus activity and native long-rest recovery. Extensive molding rules are manual.
