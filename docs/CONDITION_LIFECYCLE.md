# Batch09 condition lifecycle

Goal: finish the condition timing/allocation cases previously held manual, through source-preserving native effect updates and shared damage requests.

Ranks are capped across sources at application, with oldest-source rank loss and legacy-overflow cleanup; new ranks cannot be retained invisibly above the cap.

Turn decay removes one condition-wide budget from eligible sources, preserving applications gained during that same turn.

World-time expiry indexes only actors with pending deadlines, ignores expired penalties in prepared data and removes elapsed source records; visible unlinked actors are discovered on canvas activation.

Chilled ends outside combat, while combat movement accumulates willing distance and produces one request after more than5feet; unknown native movement classification asks the GM rather than assuming a forced move is voluntary.

Native scene measurement is converted from feet/meters, while unknown unit systems require explicit distance through the API; actual damage retains the existing manual Apply card.

Envenomed blocks native rest benefits before rest updates, and long/full condition-rest completion removes2Exhaustion only with explicit food/drink confirmation.

Full N5e rest resource conversion belongs to13, and the full-rest condition completion API is available even though native dnd5e offers only short/long rest UI.

No live test, production installation or campaign migration was performed; Batch10 remains the planned stopping milestone.
